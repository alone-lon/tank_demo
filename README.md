# 坦克大战 (Tank Battle)

基于 HTML5 Canvas + 原生 ES6+ JavaScript 开发的经典坦克大战游戏。

## 🎮 游戏特性

- **13×13 格子地图**，固定关卡设计
- **7种地形**：空地、砖墙（可破坏）、钢板（需高等级子弹）、草丛（遮挡）、河流（障碍）、基地（老鹰）
- **火力等级系统**：⭐ 道具升级火力，高等级子弹可击穿钢板
- **道具系统**：⭐ 火力升级、🛡️ 短暂无敌、💣 清屏、♥️ 加命
- **坦克碰撞**：所有坦克之间有物理碰撞，不会重叠或穿模
- **爆炸特效**：多层冲击波扩散 + 碎片粒子飞溅 + 烟雾效果
- **复活闪烁**：敌方坦克出生时0.8秒黑白闪烁动画
- **2.5D 视觉风格**：渐变、阴影、履带纹理、炮塔球面效果
- **0.5秒过场动画**：关卡切换时暂停游戏逻辑，显示过渡提示

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 空格 | 发射炮弹 |
| 回车 | 开始/重启游戏 |

## 🔧 技术栈

- **渲染**：HTML5 Canvas 2D Context
- **逻辑**：原生 ES6+ JavaScript（无第三方依赖）
- **架构**：OOP + 实体组件模式
- **输入**：KeyboardEvent

## 🚀 运行方式

直接双击 `index.html` 在浏览器中打开即可游玩，无需服务器。

## 📋 核心类

| 类名 | 职责 |
|------|------|
| `Game` | 游戏主循环、状态管理 |
| `GameMap` | 地图加载、瓦片解析、碰撞检测 |
| `Tank` | 坦克基类（位置、移动、射击、绘制） |
| `PlayerTank` | 玩家坦克（WASD控制、火力等级、无敌） |
| `EnemyTank` | 敌方坦克（AI寻路、随机射击） |
| `Bullet` | 子弹（飞行、穿透力、边界检测） |
| `Explosion` | 爆炸特效（多层冲击波+碎片粒子） |
| `PowerUp` | 道具（⭐🛡️💣♥️） |

## 🗺️ 地图说明

- **砖墙**（褐色）：可被任意子弹破坏
- **钢板**（银灰）：普通子弹无效，需火力等级≥3
- **草丛**（绿色）：遮挡显示，不影响碰撞
- **河流**（蓝色）：坦克不能通过，子弹可穿过
- **基地**（蓝底鹰）：被击中游戏结束

## 🎯 游戏目标

消灭每关全部20个敌方坦克，保护基地老鹰不被摧毁。死一个敌人立即补充一个，直到全部20个敌人都被击毙。
