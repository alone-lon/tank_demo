## 一、游戏目标与胜负条件

| 目标 | 规则 |
|------|------|
| 过关 | 消灭当前关卡所有敌方坦克 |
| 失败 | 玩家生命耗尽，或基地"鹰"被摧毁 |
| 每关敌人 | 通常 20 辆，分批次刷新 |
| 同屏敌人 | 一般保持 4 辆左右 |
| 胜利后 | 进入下一关，关卡循环 |

## 二、地图系统

地图用 **13×13 格子** 表示，每个格子放一种地形。

| 地形 | 坦克能否通过 | 子弹能否通过 | 是否可破坏 |
|------|------------|------------|----------|
| 空地 | 能 | 能 | 否 |
| 砖墙 | 不能 | 不能 | 能 |
| 钢板 | 不能 | 不能 | 普通子弹不能 |
| 草丛 | 能 | 能 | 否，但遮挡显示 |
| 河流 | 不能 | 能 | 否 |
| 冰面 | 能 | 能 | 否，但会打滑 |
| 基地鹰 | 不能 | 不能 | 被击中即失败 |

## 三、坦克系统

### 坦克属性

```python
class Tank:
    def __init__(self, x, y, direction=UP):
        self.x = x
        self.y = y
        self.direction = direction   # UP/DOWN/LEFT/RIGHT
        self.speed = 2
        self.hp = 1
        self.level = 0               # 火力等级
        self.fire_cooldown = 0
        self.is_invincible = False
        self.invincible_time = 0
        self.image = None
        self.rect = None
```

### 玩家控制逻辑

```python
def handle_input(self, keys):
    if keys[pygame.K_UP]:
        self.move(UP)
    elif keys[pygame.K_DOWN]:
        self.move(DOWN)
    elif keys[pygame.K_LEFT]:
        self.move(LEFT)
    elif keys[pygame.K_RIGHT]:
        self.move(RIGHT)

    if keys[pygame.K_SPACE]:
        self.shoot()
```

### 移动逻辑（先算位置再检测碰撞）

```python
def move(self, direction):
    self.direction = direction
    nx, ny = self.x, self.y

    if direction == UP:
        ny -= self.speed
    elif direction == DOWN:
        ny += self.speed
    elif direction == LEFT:
        nx -= self.speed
    elif direction == RIGHT:
        nx += self.speed

    if not self.map_collides(nx, ny):
        self.x = nx
        self.y = ny
        self.rect.topleft = (self.x, self.y)
```

## 四、子弹系统

### 子弹属性

```python
class Bullet:
    def __init__(self, x, y, direction, owner, power=1):
        self.x = x
        self.y = y
        self.direction = direction
        self.owner = owner         # "player" 或 "enemy"
        self.power = power         # 1=普通，3=可打钢板
        self.speed = 5
        self.alive = True
```

### 更新逻辑

```python
def update(self):
    if self.direction == UP:
        self.y -= self.speed
    elif self.direction == DOWN:
        self.y += self.speed
    elif self.direction == LEFT:
        self.x -= self.speed
    elif self.direction == RIGHT:
        self.x += self.speed

    if self.out_of_screen():
        self.alive = False
```

### 射击冷却

```python
def shoot(self):
    if self.fire_cooldown > 0:
        return

    bx, by = self.get_muzzle_position()
    bullet = Bullet(bx, by, self.direction, owner="player", power=self.level + 1)
    bullets.append(bullet)
    self.fire_cooldown = max(10 - self.level * 2, 5)
```

## 五、碰撞检测

### 矩形碰撞

```python
def rects_collide(a, b):
    return (
        a.x < b.x + b.width
        and a.x + a.width > b.x
        and a.y < b.y + b.height
        and a.y + a.height > b.y
    )
```

### 主循环碰撞处理

```python
for bullet in bullets:
    if not bullet.alive:
        continue

    # 子弹打墙
    for wall in brick_walls:
        if rects_collide(bullet, wall):
            bullet.alive = False
            wall.hp -= bullet.power
            if wall.hp <= 0:
                brick_walls.remove(wall)
            break

    if not bullet.alive:
        continue

    # 子弹打钢板
    for steel in steel_walls:
        if rects_collide(bullet, steel):
            if bullet.power >= 3:
                steel_walls.remove(steel)
            bullet.alive = False
            break

    if not bullet.alive:
        continue

    # 子弹打坦克
    if bullet.owner == "player":
        for enemy in enemies:
            if rects_collide(bullet, enemy):
                bullet.alive = False
                enemy.hp -= 1
                if enemy.hp <= 0:
                    enemies.remove(enemy)
                    spawn_powerup_if_special(enemy)
                break
    else:
        if rects_collide(bullet, player):
            bullet.alive = False
            if not player.is_invincible:
                player.hp -= 1
```

## 六、敌人 AI

### 简单版：直线前进，撞墙随机换方向

```python
import random

DIRECTIONS = [UP, DOWN, LEFT, RIGHT]

def enemy_ai(enemy):
    enemy.move(enemy.direction)

    if enemy.map_collides(enemy.x, enemy.y):
        enemy.direction = random.choice(DIRECTIONS)
        return

    if random.random() < 0.02:
        enemy.direction = random.choice(DIRECTIONS)

    enemy.fire_cooldown -= 1
    if enemy.fire_cooldown <= 0:
        enemy.shoot()
        enemy.fire_cooldown = random.randint(60, 120)
```

### 进阶版：偶尔朝基地移动

```python
def chase_base(enemy):
    base_x, base_y = BASE_POSITION
    dx = base_x - enemy.x
    dy = base_y - enemy.y

    if abs(dx) > abs(dy):
        enemy.direction = RIGHT if dx > 0 else LEFT
    else:
        enemy.direction = DOWN if dy > 0 else UP
```

```python
def apply_powerup(kind):
    if kind == "STAR":
        player.level = min(player.level + 1, 3)
    elif kind == "HELMET":

        player.invincible_time = 600
```

## 八、主循环骨架

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((416, 416))
clock = pygame.time.Clock()

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    player.fire_cooldown = max(player.fire_cooldown - 1, 0)
    player.invincible_time = max(player.invincible_time - 1, 0)
    if player.invincible_time <= 0:
        player.is_invincible = False

    handle_input(pygame.key.get_pressed())
    update_bullets()
    update_enemies()
    update_powerups()
    check_collisions()
    check_game_over()

    screen.fill((0, 0, 0))
    draw_map()
    draw_walls()
    draw_base()
    draw_player()
    draw_enemies()
    draw_bullets()
    draw_powerups()
    pygame.display.flip()
    clock.tick(60)
```
